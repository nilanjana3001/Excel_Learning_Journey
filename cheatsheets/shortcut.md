# Essential Excel Keyboard Shortcuts

Here are the first 10 shortcuts I practiced for faster navigation and data entry on Windows:

It's also a basic concept of EXCEL worksheet.

| Shortcut | What It Does 

 **`Ctrl + Arrow Keys`** =  Jumps to the edge of the current data region. 

 **`Ctrl + Shift + Arrow`** =  Selects all cells from the active cell to the edge of the data. 

 **`Ctrl + Space`** = Selects the entire column. 

 **`Shift + Space`** = Selects the entire row. 

 **`F2`**  = Edits the active cell directly without using the mouse. 

 **`Ctrl + D`** = Fills down the value or formula from the cell directly above. 

 **`Ctrl + ;`** = Inserts today's current static date. 

 **`Alt + =`** = Automatically inserts the `SUM` formula (`AutoSum`). 

 **`Ctrl + 1`** = Opens the **Format Cells** dialog box. 

 **`Ctrl + Z` / `Ctrl + Y`** =  Undoes (`Ctrl + Z`) or redoes (`Ctrl + Y`) your last action. 

 **`ctrl + right arrow`** = Reach last column.


 **`shift +F11`** = New sheet add in the left of current sheet. 

 **`ctrl + Page Up/ Page Down`** = sheet navigate.

 **`ctrl + w`** = wordbook close.

 **`ctrl + n`** = new wordbook.

 **`ctrl + o`** = Open existing wordbook.

 **Ctrl + E** = Automatically fills data patterns (Flash Fill).
